# task-mgmt-app-react

Task Management WebApp created by Tricia Wittsack.

This WebApp will create and manage ToDo items.  The API will allow creating items for the ToDo list, Updating items for the ToDo list, Marking the items as completed, and Deleting the items for the ToDo list, if necessary.

The WebApp is created using CSS, JavaScript, and React.  A json file is used for storing the ToDo items.  
- The contact webpage will be used by other individuals to present a New ToDo item or request an update on an existing ToDo Item.  
- The todos webpage will allow adding a new task, viewing a list of all tasks, completed tasks, or incomplete tasks.  Additionally, the todos webpage will allow tasks to be updated, marked complete or deleted.

**User Stories**

- As a user, I want to be able to add Tasks to the ToDo List.
- As a user, I want to be able to update Tasks in the ToDo List.
- As a user, I want to be able to mark Tasks as completed in the ToDo List.
- As a user, I want to be able to delete Tasks in the ToDo List.
- As a user, I want to be able to initiate contact concerning Tasks in the ToDo List.

- As a developer of the WebApp, I want to capture Tasks for the ToDo List.
- As a developer of the WebApp, I want to update the Tasks for the ToDo List.
- As a developer of the WebApp, I want to be able to mark Tasks in the ToDo List as completed.
- As a developer of the WebApp, I want to delete Tasks in the ToDo List.
- As a developer of the WebApp, I want to update a json flat file with contact info & task info.
